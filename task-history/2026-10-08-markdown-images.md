# Markdown 图片显示

问题：会话 `01a11b05-b8de-7e91-97d2-2214313353ed` 的助手成功生成截图，却因 Markdown 图片渲染器只输出文字标签而无法在聊天中显示。

实现：Markdown 图片保留经过转义的惰性占位符，由 Vue 图片组件显示。HTTP/HTTPS 和栅格 data URL 直接加载；本地路径通过会话所属设备的现有 `createWorkspaceFiles` 接口读取，绝对路径不依赖 cwd，相对路径按会话或 Markdown 文件所在目录解析。主对话和侧边对话分别提供自己的设备上下文。保留 HTML 净化和原始 `img` 标签禁用规则，实际图片由 Vue 创建。

交互：原位图片、自适应宽度、点击放大、关闭后恢复键盘焦点、加载提示、失败重试。卸载或上下文变化时取消远端读取并忽略过期结果。远端文件预览沿用现有 PNG/JPEG/GIF/WebP 和 8 MiB 上限。

验证：

- `bun run build` 通过（包含类型检查）。
- Markdown、文件链接及远端文件读取相关单元测试共 46 项通过。
- 图片专项浏览器测试在桌面和手机通过：`/tmp/...png`、HTTP 图片、放大、Escape 关闭及焦点恢复、读取失败重试、文档相对图片；未出现浏览器脚本错误或误向网页源请求 `/tmp` 的情况。
- 文件预览浏览器回归测试的 13 项通过；桌面侧栏关闭动画测试失败（340 ms 中宽度过渡样本不足）。将本次修改的既有源文件恢复为 HEAD，在独立临时目录构建基线后，同一测试仍以同一断言失败，确认不是本次图片改动引入。未改动该测试或动画。
- `git diff --check` 通过。

测试运行时移除了进程的 `http_proxy`、`https_proxy`、`all_proxy`，避免本机测试服务健康检查被环境代理拦截；未修改用户代理设置。
