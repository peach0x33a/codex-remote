# Portable appearance, file browser and conversation presentation

Date: 2026-10-04

Requests: animate the conversation when closing the file panel; export/import appearance including background and font names; support network background URLs; set a browsed directory as the working directory; create folders and files; visibly identify subagent conversations; parse and render file changes; reduce Session ID field height; render HTML files; align thinking text and icons.

Implemented:
- Docked file-panel geometry and conversation width animate together on opening and closing, retaining departing content until exit completes. Mobile overlays avoid resizing the conversation; reduced motion disables spatial transitions.
- Appearance settings expose versioned JSON export/import for theme, content width, wrapping, typography names/sizes, background mode and image effects. Uploaded images are embedded; remote images retain their URL. Validation and image decoding precede application, invalid imports preserve current settings, and export excludes credentials and connection preferences. Fonts themselves are not bundled.
- Network backgrounds accept HTTP/HTTPS URLs without embedded credentials. The browser decodes the image directly with no referrer, without a Bun proxy or CORS requirement; loading errors preserve the previous background. IndexedDB retains uploaded images or remote URLs. The bridge CSP now permits these image sources.
- Directory actions set the directory for a new conversation through the existing project selection path, create folders, or create empty files. Existing conversations retain their cwd. Creation captures the parent, validates names and uses a fixed remote Python script with separate argv, exclusive creation and directory handles; it never overwrites existing files, folders or symlink targets, and does not automatically retry uncertain writes.
- HTML/HTM files with complete bounded reads default to a static HTML/CSS/SVG preview in a sandboxed srcdoc frame. Source tabs, line-targeted source navigation and downloads remain available. Scripts, forms and top navigation are blocked; base/refresh elements and relative image sources are removed to prevent incorrect app-origin requests. This is a static preview, not an executable website or a relative-asset server.
- Explicit robot-and-text subagent badges appear in the sidebar, conversation header and details. Identity uses native parentThreadId/subAgent metadata and compatible legacy spawn metadata; ordinary forkedFromId alone does not mark a subagent. Details show the actual agent name/role and parent-conversation action. Native type semantics were checked against installed CLI 0.159.0 generated types.
- Native fileChange activities use per-file cards with file icons, paths, change type, accurate available counts and the existing numbered green/red DiffCode rendering. Add/delete data is full file content, update/move data is unified diff. Unknown, oversized or unparseable changes retain readable originals and omit invented counts.
- Session ID is now a selectable content-sized field instead of a fixed two-row textarea. Copy remains explicit and restricted to the context popover; copy failure does not open a window or select text.
- Inline thinking icons align to the first text line using its scaled line height, including wrapped text. Existing sanitized Markdown and native duration semantics remain intact.
